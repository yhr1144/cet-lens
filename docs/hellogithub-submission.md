## 项目简介（30 字内）

拍纸质卷子变可点词电子稿，手写作文可 AI 批改的四六级 App。

## 推荐理由

- **内容随包**：76 万条词库、141 篇原创短文、144 条句式库全部内置，查词和阅读不需要网络；离线 OCR 走本机 ML Kit
- **两档识别**：印刷体用本机识别（免费、1–2 秒），手写体切云端 OCR（DeepSeek 接口，按页计费约 ¥0.0016）
- **批改按四六级官方 15 分档**：作文和翻译各用一套官方档位描述定档，跨档取低档，字数明显不足封顶 7–9 档；输出档位理由、分项拆解、扣分说明、逐词替换建议
- **AI 自备 Key**：Key 只存本机，不经过任何中间服务，开发者不收分成
- **工程上有点意思**：单 APK 内嵌本地 HTTP 服务（127.0.0.1:19003）承载前端；构建链是 aapt2 → javac → d8 → zipalign → apksigner，`build.ps1` 一条命令出包，不依赖 Gradle

## 截图

（按顺序拖入这三张：扫描识别 / 词库详情 / 批改结果）

1. 手写作文拍照识别，结果里单词可点击查词
2. 词条详情：释义、同义替换（标注适用语境）、双语例句
3. 批改结果：写作 9/15（7-9 档）、翻译 8/15，主观题合计 120.7/213

## 补充

MIT 开源，未上架应用商店，当前通过 GitHub Release 与国内网盘分发，安装包 72 MB，支持 Android 7.0 及以上。

作者非科班开发者，产品判断与真机验收由本人完成，代码由 AI 编程助手按需求实现，README 里有分工说明。
